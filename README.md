# 森林調査ノート（公開デモ）

林業の森林調査を題材にした、就職活動向けの学習用アプリです。班、調査区域、個体番号、樹種、胸高直径、樹高を入力し、樹種ごとの本数を集計します。

## このデモについて

- Excelの元データは読み込みません。最初は記録なしで始まり、画面から入力します。
- 樹種名は自由入力できます。
- 入力した記録はアプリのSQLiteデータベースに保存し、CSVでダウンロードできます。
- 公開デモでは架空の記録だけを入力してください。Streamlit Cloudではローカルファイルの永続保存が保証されないため、実際の森林調査データには使わないでください。
- ローカルで同じWi-Fiのスマートフォンから使う場合は、アプリを起動しているパソコンがサーバーになります。

## 起動方法

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## 使用技術

- Python
- Streamlit
- pandas
- SQLite
