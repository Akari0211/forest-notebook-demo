# 森林調査ノート（公開デモ）

林業の森林調査を題材にした、就職活動向けの学習用アプリです。
班・調査区域・個体番号・樹種・胸高直径・樹高を入力し、樹種ごとの本数を自動集計します。

## デモのデータ

初期表示の記録は架空データです。公開用フォルダーには、個人情報や元の研究Excel、ローカル入力履歴を含めていません。
このデモで追加した記録はブラウザーのセッション内だけで扱い、永続保存しません。実際の調査データには使わないでください。

## 起動方法

```text
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## 使用技術

- Python
- Streamlit
- pandas
